# Pixel Gesture 0.6.0

This release focuses on open-source readiness, responsiveness, power efficiency, and automated quality controls while preserving all existing gesture bindings and bilingual behavior.

## Changes

- Complete GitHub repository structure under GPL-3.0-only
- English-first and Simplified Chinese documentation
- CI builds, Android Lint, catalog unit tests, and translation-parity verification
- Installed-app discovery moved off the main thread
- Monotonic gesture timing for reliable double taps and long presses
- Lower-power shake sampling
- R8 and resource shrinking enabled for Gradle release builds
- Gradle distribution checksum verification
